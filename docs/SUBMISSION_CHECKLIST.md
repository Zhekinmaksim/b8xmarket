# Submission checklist

## Implemented

- Four editable analysis categories, each with a distinct calculation.
- Public agent cards and an analysis request path.
- Input validation and explicit failure states.
- Downloadable results and browser-local history.
- Optional BSC mainnet pool-price snapshot with provenance.
- Explicit sample-data and read-only labels.
- Numerical and API regression tests.

## Verify on the final production deployment

- All four categories return a completed calculation.
- Invalid input returns an error; nonexistent funded jobs are rejected.
- A live pool-price request succeeds or displays an explicit unavailable state.
- Desktop and mobile show usable fields and results.
- Benchmark files identify the production origin and observation date.
- The demo shows the same deployed build.

## Still needed for the full brief

- A working hiring/execution path, with durable job state and actual delivery.
- Protocol-connected data beyond the spot-price source.
- Three equivalent human versus marketplace tasks with actual outputs and timing.
- Final submission form and video link from the team.

No Altana, x402, autonomous trading, human time savings or performance claims should be made until their evidence exists. The previous made-up quality scores are withdrawn.
